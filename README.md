# Анализ и автоматизация обработки данных о профессиональном выгорании медицинского персонала

Репозиторий содержит материалы магистерской диссертации, посвященной исследованию факторов выгорания сотрудников здравоохранения одного из регионов РФ и созданию сквозного автоматизированного конвейера обработки данных (Data Pipeline).

В основе проекта лежит анализ масштабного регулярного исследования ФГБУ «ЦНИИОИЗ» Минздрава России

## О проекте

Репозиторий содержит:
- предобработку данных
- исследовательский анализ данных (EDA)
- обучение и оценку моделей
- ноутбуки с экспериментами и результатами

## Основноц стек технологий

- Python (Pandas, Scikit-learn)
